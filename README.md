# 校园办事向导

参赛作品：2026 首届智能体节「智启未来·体创万象」· 管理类 · 单人。
一句话：学生问“校园卡丢了怎么办”，它不只回答，而是给出一张**能打印带走的单子**——时间线、材料清单、文书草稿，还能拍照核对缺哪样。

当前版本：**v0.5**（2026-10-30）。21,142 条事项（23,876 个可追溯字段）/ 1,146 份语料 / 189 条校园地点词条 / 16 个学院转专业计划 / 14 个多选项菜单。

## 快速开始

1. 把 DeepSeek API Key 写进 **`.env`**（没有 Key 也能跑，只是不能拍照核对）：

   ```
   DEEPSEEK_API_KEY=sk-你的key
   ```

   ⚠️ **不要写进 `.env.example`**——那是模板文件，会随仓库公开；`app.py` 只读 `.env`。
   `.env` 已在 `.gitignore` 里，不会被提交。放错位置时，启动日志会打印提示。

2. **双击 `start.bat`**。首次会建虚拟环境并装依赖（约 1 分钟），之后直接起服务并打开浏览器。
   也可以手动：

   ```
   .venv\Scripts\python.exe -m uvicorn app:app --port 8000
   ```

3. 打开 <http://127.0.0.1:8000>，输入“校园卡丢了怎么办”试试。
   带参数可直接演示：`/?q=我要开个证明`

### 两个界面

- `/`：新版双栏界面（默认）。问「一教在哪」「中传礼堂在哪」会在左侧弹出地图抽屉并定位；
  问「饭卡丢了怎么办」会给出办理地点 + 三步流程；问学院转专业会按专业列出接收计划。
- `/classic`：旧版单页界面，保留全部功能；位置答案附「在地图上打开」。
- 两个界面右上角可互相切换，访问路径不同，后端与数据完全一致。

回答里出现的校园地点都是链接：点一下会自动追问「X 在哪」，返回官方位置并弹出地图抽屉。
直接输入 `1`、`48` 这类数字，会按楼号回答（1 → 1号楼即一教，48 → 48号楼即 48教）。

新版前端由 FastAPI 直接托管，生产环境不需要单独起前端服务。只在调样式时用预览模式：

```
python -m uvicorn app:app --port 8077          # 先起接口
python web-next/serve.py 8090                 # 再起预览（/api 自动反代到 8077）
```

打开 <http://127.0.0.1:8090>。

## 从 GitHub 部署到另一台机器

仓库里是能直接运行的代码，但有三样东西按设计不入库，换机器时补上就与本地一致：

| 没入库的 | 影响 | 怎么补 |
|---|---|---|
| `.env`（DeepSeek Key） | 只有拍照核对不可用，问答不受影响 | 复制 `.env.example` 为 `.env`，填 Key |
| `sources/` 正文（归档包） | 问答不受影响；`check_quotes.py`、原文检索需要 | 解压 `sources-archive.tar.gz` |
| `sources/vector/`（约 74 MB 索引） | `/api/search` 返回 503，规则没命中时少一层原文线索 | 跑 `tools/build_vector.py` 重建（约 1–2 分钟，纯本地计算，不联网） |

> 事项库在仓库里是 `items.json.gz`（明文 31 MB，压缩后 2.8 MB）。`app.py` 两种都认：有明文读明文，没有就自动解压 gz，**运行不需要手动解压**。只有当你跑 `check_quotes.py` 这类只认明文的脚本时，先执行 `.venv\Scripts\python.exe tools\unpack_items.py`。

Windows（Python 3.11+）：

```bat
git clone https://github.com/uwu9039/cuc-campus-guide.git
cd cuc-campus-guide
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
tar -xzf sources-archive.tar.gz
.venv\Scripts\python.exe tools\build_vector.py
.venv\Scripts\python.exe -m uvicorn app:app --host 0.0.0.0 --port 8000
```

macOS / Linux（Python 3.11+）：

```bash
git clone https://github.com/uwu9039/cuc-campus-guide.git
cd cuc-campus-guide
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
tar -xzf sources-archive.tar.gz
python tools/build_vector.py
python -m uvicorn app:app --host 0.0.0.0 --port 8000
```

`tar` 用系统自带的即可，解出来就是 `sources/...`，不会多一层目录。启动后打开 <http://127.0.0.1:8000>：
新版界面在 `/`，旧版在 `/classic`。
16 份转专业计划原始 PDF 已随仓库提供，`/api/plan-file` 可直接下载；其余 PDF/DOCX 只保留抽取后的文本（在归档包里）。
视频样片、采集中间产物（`dist/`、`aia-runs/`、`wendao/`）和隔离语料不在仓库里，也不影响运行。

## 热加载（开发时不用重启）

| 改什么 | 怎么生效 |
|---|---|
| `app.py` | uvicorn `--reload` 自动重启，约 1 秒 |
| `items.json` | 按 mtime 检测，**刷新页面即生效**，不重启 |
| `.env`（换/删 Key） | 按 mtime 检测，下次请求即生效，**不重启** |
| `index.html` | 响应带 `Cache-Control: no-store`，刷新即生效 |

`start.bat` 是开发模式（带 `--reload`）。
**录演示视频或现场答辩请用 `start-demo.bat`**：无文件监听、无重启空窗，更稳。

## 架构

```
浏览器（新版 web-next 默认 /，旧版 index.html 在 /classic，均无构建）
   ↓
FastAPI（app.py）
   ├── items.json(.gz)   → 21,142 条结构化校园事项（21,110 条有原文正文）
   ├── sources/          → 1,146 份官方原文 / 7,622 段向量（只做辅助检索）
   ├── transfer-plans.json → 16 个学院转专业接收计划（88 个专业、94 个年级块）
   ├── campus-map.json   → 37 个地图 POI；接口共 189 条地点词条，问答联动高德地图
   ├── 别名+关键词打分    → 意图识别（确定性，零 token）
   ├── 模板拼装          → 文书草稿（确定性，模型不参与）
   └── deepseek-flash 视觉 → 拍照核对材料（唯一用到模型的地方）
```

**设计原则：能算的不用模型。** 意图识别用别名表 + 关键词 + 二元组相似度打分；交付物和文书由 items.json 直接装配；
模型只做一件它真擅长、又不承担事实责任的事——**看照片核对材料**。答不出来就直说查不到，不编。

> 这里踩过一个坑并已修：早先让模型补全申请书里的「情况说明」，它写出一句
> “因个人课程安排冲突”（用户从没提过）。文书里出现一个不存在的理由，比留空危险得多，
> 于是改成纯模板拼装，信息不足就留【请补充具体原因】让人自己填。
>
> 另一个坑：`deepseek-flash` **默认开思考模式**，思考 token 会先吃掉 `max_tokens`，
> 短任务容易返回空内容。现在所有短调用都带 `"thinking": {"type": "disabled"}`，稳定在 1–2 秒。

## 问答层：先把问题翻译成「能答的问法」

用户不会按字段提问。所以输入先被归一化，再作答：

```
「成绩单密封章几点能办」
   ↓ 归一化
【成绩单办理 · 办理时间】          ← 界面直接显示这句，让你看见我怎么理解你的
   ↓ 只答这一面
密封章：周二、周四 14:00–16:30（节假日除外）
原文“每周二、周四14:00-16:30（节假日除外）到艺术传播大楼三等东侧办公室现场核验并密封”
   ↓ 完整记录折叠在下面
＋ 完整事项 · 时间线 / 材料清单 / 文书草稿 / 拍照核对
```

- 一次可带两个面：「几点、在哪办」→ 同时答时间 + 地点
- **数据里没有这一面，就直说**：「体育免修多少钱」→「官方页面没有写这一项」+「我不替它编」
- 问得太泛（只说“补卡”）→ 回到整体流程，不硬猜你问哪一面

评测里单独有 12 条聚焦用例（问时间/地点/费用/材料/时限/易错/双面），当前 **12/12**。

## 追问是当场算出来的，不是一张固定问卷

每条事项的字段决定了「分支」：哪些条件会改变答案。系统只问**还缺的、且真的会改变这一问答案的**问题。

```
「选课什么时候截止」
   → 理解成【补（退）选课 · 办理时限】
   → 但时限取决于这门课第几周开课 → 先问：
     这门课是第几周开始上的？  第一周 / 晚于第一周
       为什么问：非首周开课的课程才有单独的退课通道，时限也不同
   → 你选「晚于第一周」→ 才给出时限
```

规则：

| 情况 | 行为 |
|---|---|
| 你已经说了 | 不重复问。「成绩单要**密封**盖章」→ 不再问“需要密封吗”，只补问“哪一届” |
| 与这一问无关的条件 | 不问。「在读证明几点能办」→ 不问户籍，因为时间跟户籍无关 |
| 会改变答案的条件 | 先问后答，并说明为什么问 |
| 答完还缺信息 | 分支过滤：知道“非京籍 + 因私出国”就只给那一条路，不把三个分支全甩给你 |

实测：「在读证明怎么办」→ 问用途 → 问户籍 → 答“填四份表格，持表到本科生院办盖章”（京籍则答“可信系统自助下载”）。

## 数据状态与证据链

**规则：数据层只放官方原文，联想放联想层。**

- 1,146 份语料抓取留档在 `sources/`（含 sha256 与抓取时间），页面改版也能对照当时原文
- 其中 52 个 PDF/DOCX/XLSX 原始文件全部有对应抽取文本，向量库覆盖 903 份 / 7,622 段
- 16 个学院的转专业接收计划已**整份**结构化：88 个专业、94 个年级块，条件 / 材料 / 考核 / 联系方式 / 备注逐条保留，另存整份 PDF 转出全文；答案底部可直接打开原始 PDF
- 2026 年版《本科专业简称》103 条、18 个学院全部导入 `major-aliases.json`。支持“游技 / 播本 / 电音 / 光环境 / 数媒技 / 动院 / 计网院”等叫法；专业名、简称、方向名三条路都能路由到对应学院和计划专业
- 规则路由 87/87（学院问法 + 简称问法）；规则仍是主系统，向量只做兜底
- 21,142 条事项、**23,876 个字段带 evidence 引文，0 条缺证据**（步骤 / 材料 / 费用 / 地点 / 时间等结构化事实同样逐字段挂引文）
- 公告类事实同样逐字入库：校园网恢复计量计费公告按 2026-10-29 校园公告页面截图逐字转录，拆成 17 条独立事实
- 校验方式是**子串匹配**：`tools/check_quotes.py` 逐条比对 quote 是否为原文子串，对不上退出码 1
- 21,110 条有实质正文（21,107 条 `verified` + 3 条 `partial`）；32 条 `source-thin`（官方页面本身没有正文）

> 发布说明：公开的官方电话、邮箱、办公地点按原文保留在数据里，不做打码；
> 只清除本机路径、账号凭证与个人身份信息。

界面里，事实下方挂折叠块「＋ 原文摘录（N 条，逐字来自官方页面）」；建议类内容单独放在
「提示（非官方原文）」块里，视觉上不混。

```bash
.venv\Scripts\python.exe tools\fetch_sources.py   # 重新抓官方页面
.venv\Scripts\python.exe tools\check_quotes.py    # 校验每条事实的来源（改动后必跑）
.venv\Scripts\python.exe tools\check_slots.py     # 校验「反问分支」：有条件的步骤必须问得出来
```

反问层只在该条目真的分情况时出现（如快递驿站分校内 / 梆子井、成绩单分密封 / 不密封）；
单句事实条目不做假问，直接答原文。

## 加完材料后的固定动作

```bash
.venv\Scripts\python.exe tools/pipeline.py
```

依次跑：证据校验 → 关键词归属 → 预置问法 → 向量库（缺失或加 `--vector` 时重建）→ 口径核对 → 重点问法 → 学院转专业 → 评测 → 路由审计 → 敏感词推导。任一步失败都会非零退出；`--fast` 跳过 LLM 对比。
其中敏感词表（`sensitive.json`）不是手写的，由压测结果推导：**出现该词时错误跳转率显著高于基线的词才算**。
